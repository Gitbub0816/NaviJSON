NaviJSON SDK — embeddable map

This page loads /sdk/navijson.js and mounts a NaviJSON map into the box below. Paste a real Mapbox public token (pk.…) into the token option to get the live Mapbox map with tap-to-route, drive simulation, and voice guidance. Without a token, the keyless canvas preview renders instead.
